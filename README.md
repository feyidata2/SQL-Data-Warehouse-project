# Modern Sales Data Warehouse Project

## Project Overview
This project builds a modern data warehouse using SQL Server to consolidate sales data from multiple sources. The goal is to enable analytical reporting and support informed business decision-making.

## Objective
Develop a SQL Server-based analytics solution that delivers insights into:
- Customer behavior
- Product performance  
- Sales trends

Empower stakeholders with key business metrics to enable strategic decision-making.

## Data Sources
Data is imported from 2 systems:
1. **ERP** - Enterprise Resource Planning system
2. **CRM** - Customer Relationship Management system  

Data is provided as CSV files.

## Data Quality & Processing
- Clean and resolve data quality issues from both sources
- Standardize formats and handle missing/invalid data
- Combine both sources into a single, user-friendly data model optimized for analytical queries

## Project Scope
- Focus on the latest dataset only
- Historical data tracking is not required
- Designed for current-state analysis and reporting

## Documentation
Clear documentation of the data model is provided to make the warehouse easy to understand and use for analysis.

## BI, Analytics & Reporting
The warehouse supports BI tools and SQL-based analytics to uncover actionable insights for business growth.
